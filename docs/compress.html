Сжать PDF под лимит

Бесплатно, в браузере. Текст и вектор сохраняются, сжимаются только изображения. Файл никуда не загружается.

Обработка локальная (Ghostscript в WebAssembly). Первый запуск грузит ~14 МБ — дальше из кэша. Ниже 72 dpi не опускаемся: если в лимит не влезает при читаемом качестве — честно скажем.

Нужна гарантия приёмки, срочность или файл 30+ МБ? Тарифы.
